ZeroTrace: обзор архитектуры

Один backend принимает реальные трейсы, управляет конфигурацией и собирает результаты прогонов.

Общий обзор

React UI и HTTP API работают с одного origin. Backend обслуживает телеметрию, управление и аналитику; данные всех потоков сохраняются в общей SQLite базе.

На узком экране схему можно прокручивать по горизонтали. Для слайда используйте «Скачать SVG» или печать в PDF.
