# Проверка интерфейса после унификации

Проверено 12 ноября 2026 года, локальный Vite и демонстрационный Client.

## Автоматические проверки

- `npm test`: 57 тестов, включая совместимость новых страниц с существующей маршрутизацией.
- `npm run build`: TypeScript и production bundle.
- `npm run docs:check`: синхронность руководства и наличие его изображений.
- `git diff --check`: отсутствие ошибок форматирования diff.

## Проверка браузером

| Область | Проверено |
|---|---|
| Подключение | Переключение в demo, состояние текущего подключения |
| Трейсы | Таблица, ошибка невалидного Span ID, очистка и открытие трейса |
| Общие контролы | Поля поиска и списки высотой 44 px, текст ввода 16 px |
| Трейс | Временная шкала, инспектор, ссылки и экран на 390 px |
| Сервисы | Граф, статистика, заголовки 16 px и подписи графика 14 px |
| Система | Раскрытие статистики, выбор точки клавишей Enter и обновление деталей |
| Аудит | Проблема, история, открытие и закрытие плана, адаптивный диалог |
| Стенд | Создание примера, выбор orders, форма имитации ошибок |
| Результаты | Демозапуск 10 запросов / параллельность 1 / Seed 42, завершение и графики |
| Руководство | Переход по содержанию, загрузка всех 10 основных скриншотов |
| Лендинг | Презентация, навигация и широкая/узкая композиция |

На 1440 px проверены основные экраны. На 390 px проверены все разделы,
отдельно трейс, диалог и результат теста. У документа нет горизонтального
выхода за viewport. На 320 px проверены подключение и таблица запросов;
на 768 px — переход к боковой навигации и таблица.

На мобильном все 7 столбцов трейсов остаются видимыми в таблице шириной
920 px, прокручиваемой внутри контейнера. Навигация сохраняет текст 16 px
и иконки. Графики сохраняют читаемый масштаб и собственную прокрутку.

## Границы проверки

Серверный код и API-контракты не менялись. Реальный OTLP, запись конфигурации
в live-сервисы, реальные HTTP-прогоны, iOS Safari и Android Chrome в этой
проверке не запускались. Демозапуск проверяет интерфейс, но не реальную нагрузку.
Скриншоты в `frontend/public/guide/` получены из итогового интерфейса в demo.

Проверка реального backend выполнена отдельно: [отчёт live-проверки](live-verification.md).
