# ZeroTrace frontend 0.2

Интерфейс системы аудита retries/timeouts и исследования трасс, созданный с нуля. Оформление опирается на ZeroTrace с рабочего стола: тёмная палитра, сиреневый акцент, компактные таблицы и тонкие границы.

## Запуск

Node.js 22 и npm. Для интерфейса не нужны Linux, Docker или Python.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/. Сборка: `npm run build`; предпросмотр сборки: `npm run preview` (4173). Проверки: `npm test`.

Основное меню: трассы, граф, таймауты и повторы, аудит. Дополнительные разделы открываются через «Ещё». Основные представления переключаются вкладками: карта/связи, редактор/текущие настройки, решение/обоснование/примеры. Раскрывающихся блоков внутри рабочих экранов нет. Подробности изменений — UX_SIMPLIFICATION.md.

## Рабочие разделы

- **Трассы**: поиск, фильтры, сортировка, страницы, дерево и waterfall, сворачивание веток, инспектор span, JSON-отчёт.
- **Граф сервисов**: связи по реальным parent refs загруженных спанов, направление вызовов, поиск, фильтр проблем, масштаб, выбор узла/ребра, ошибки, медиана/p95 и переходы к трассам. Из выбранной связи можно открыть план рекомендации или редактор параметров.
- **Время сервисов**: число серверных операций, медиана, p95, ошибки/неизвестный исход, суммарное время вне объединения дочерних интервалов. Последнее не является CPU-временем.
- **Таймауты и повторы**: подтверждённые конфигурации из config-aware находок, источник/ревизия, редактор таймаута, попыток, фиксированной паузы и верхнего бюджета, расчёт резерва и экспорт ручного черновика. Исходный серверный план рекомендации открывается отдельно.
- **Сравнение групп**: ручной выбор непересекающихся групп одной операции, быстрое разбиение по исходу, медиана/p95/число ошибок, экспорт. Различия описывают выборку и не доказывают причинность.
- **Аудит**: находка R4 с evidence, provenance, confidence, примерами, рекомендацией и рисками; явные статусы остальных правил.
- **Журнал** и **Подключение**: история от сервера, настройка и проверка API без подмены ошибок демоданными.

Внутри трассы вкладка **«Что если»**: до восьми непересекающихся веток, ползунки ускорения, проекция длительности входа, кандидаты при ускорении на 50%, экспорт сценария. Применяется локальная предварительная модель interval blocks с ограничениями, взятыми из Go-прототипа. Полноценная совместимость с аналитическим API Go не заявляется.

## Источники и границы

По умолчанию включены явно помеченные **демоданные**. Реальные приложения не подключены. API режим использует только ответы указанного сервера, контракт в API.md. Сервер при другом origin должен разрешать CORS.

Аудиторские находки формируются сервером/fixtures, правила R1–R8/D1 в браузер не перенесены. Локально считаются описательная статистика загруженной выборки, фиксированный бюджет ручного черновика и исследовательская проекция интервалов. Проекция не моделирует retry policy, новую нагрузку, кэш или фактическое исполнение. При неполноте, циклах, неизвестных родителях, неверных границах и пересечении выбранных веток проекция блокируется.

Граф загружает максимум 100 деталей трасс, по четыре запроса одновременно, до 2000 спанов в каждой; карта ограничена 40 сервисами. Ошибки загрузки отмечаются, статистика относится только к полученной выборке. На больших объёмах нужны серверные агрегаты. У p95 малой выборки нет статистической устойчивости.

Редактор не меняет приложение. Экспорт содержит `applied:false` и не является исполняемым серверным планом. Frontend не отправляет apply, даже если сервер сообщает `apply_enabled:true`. Не подключены полный реестр политик, управляющий адаптер, chaos-управление стендом, анализ структуры операций групп и OTLP upload UI.

## Компоненты и интеграция

Шесть общих элементов в `components/ui.tsx`: Icon, Button, Badge, Panel, EmptyState, Message. Общие вкладки в `components/Tabs.tsx` поддерживают стрелки, Home и End. Составные компоненты: PlanDialog, WhatIf и переиспользуемая FindingCard. Общий CSS с токенами. Без UI framework, графической библиотеки, роутера и state manager.

`src/views/` — экраны; `src/api/` — типы, fixtures, клиент; `src/analysis.ts` — локальные модели исследования. Hash-ссылки работают на статическом хостинге. Python backend и исходные Go/Rust репозитории не изменены.

26 автотестов проверяют контракты, ошибки, отмену, фильтры, дерево, наблюдаемую статистику, бюджеты, группы и ограничения проекции. Production build включает строгую TypeScript-проверку. Browser smoke и результаты описаны в FRONTEND_PLAN.md. Реальный Python backend пока не проверен end-to-end.
