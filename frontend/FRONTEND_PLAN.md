# План и результат фронтенда на 10 ноября 2026

Роль D: Хамза, руководитель и фронтенд. Исходные репозитории и Python backend не изменялись.

## Целевой срез с двумя режимами

В мониторинге общий граф показывает все наблюдаемые сервисы. Действия с конфигом зависят от возможностей выбранного сервиса и поля. В лаборатории доступны задержки, HTTP-ошибки и сравнение прогонов. Кнопка «Применить рекомендацию» доступна только для поддерживаемых настроек стенда. Во внешней системе рекомендации видны, доступ к ручному редактированию определяется отдельно. Demo/live текущего клиента остаётся выбором между демоданными и сервером.

## Проверка

- 26 автотестов: контракты, неизвестные значения, отмена и HTTP ошибки, union интервалов, число вызовов без двойного учёта client/server пары, бюджет n попыток/n−1 пауз, группы, последовательные/параллельные ветки, монотонность и отклонение непригодных деревьев.
- Production build и строгая TypeScript-проверка.
- Browser smoke: граф → связь → параметры; подстановка рекомендации даёт 1650 мс/резерв 350 мс, ручное увеличение таймаута даёт превышение; группы A/B; healthy trace → What-if с 340 до 282,4 мс при ускорении ветки на 50%; фильтр проблем графа; мобильные экраны.
- В браузере проверена загрузка JSON-черновика: applied=false, требуемый бюджет 1650 мс; пример сохранён в fixtures/policy-draft-example.json. Ошибок JavaScript в console при финальной проверке нет.
- На 390 px граф, редактор и сравнение групп не увеличивают ширину документа сверх viewport.
- Ранее проверены поиск/empty/unknown/pages, waterfall, plan/Escape, journal empty и недоступный API.
- Скриншоты новых экранов находятся в screenshots/. Реальный backend, CORS и применение настроек не заявляются проверенными.
