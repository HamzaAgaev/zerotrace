# Упрощение интерфейса ZeroTrace

10 ноября 2026. Актуальное уточнение: по обратной связи сворачиваемые блоки внутри рабочих экранов заменены вкладками и обычными блоками. Единственный details остался для «Ещё» в навигации. Таблица ниже описывает предыдущий этап упрощения; актуальные изменения перечислены в конце.

Изменения применены к frontend, backend и аналитические формулы не изменялись.

## Основание

NN/g рекомендует сначала показывать сведения и действия, необходимые для текущей задачи, а второстепенные функции раскрывать по запросу. Минимализм оценивается полезностью информации для задачи, а не количеством пустого места.

Источники:
- [Progressive Disclosure, NN/g](https://www.nngroup.com/articles/progressive-disclosure/).
- [Aesthetic and Minimalist Design, NN/g](https://www.nngroup.com/articles/aesthetic-minimalist-design/).
- [8 Design Guidelines for Complex Applications, NN/g](https://www.nngroup.com/articles/complex-application-design/).

Ниже — применение этих принципов к нашему интерфейсу. Решения не являются результатом пользовательского исследования.

## Что было лишним по умолчанию

| Раньше | Теперь | Причина |
|---|---|---|
| Восемь равнозначных разделов | Четыре основных; время, группы, журнал и подключение в «Ещё» | Быстрее найти основной сценарий аудита |
| Повтор названия проекта в workspace, аватар, служебная версия, декоративный footer | Удалены | Не помогали исследовать проблему |
| Demo-баннер плюс повторные обозначения режима | Постоянный маркер «Демоданные» в шапке, статус в desktop sidebar | Режим остаётся понятным без большого баннера |
| Четыре крупные карточки чисел перед графом и списком | Короткая строка сводки | Содержание экрана начинается выше |
| Пустой инспектор графа постоянно занимал колонку | Появляется при выборе, закрывается кнопкой | До выбора нужна карта, после — сведения о связи |
| p95 и длительности на всех узлах и связях | Число операций/вызовов; длительности в инспекторе | Меньше конкурирующих подписей |
| Граф и его таблица одновременно | Таблица раскрывается по запросу | Дублирующие представления не занимают экран одновременно |
| Расчёт, источник, объяснение и coverage аудита развёрнуты | Проблема и рекомендация видны, доказательства раскрываются | Отделены решение и проверка его основания |
| Четыре поля редактора и таблица источника сразу | Два основных поля; пауза/бюджет и источник раскрываются | Меньше параметров для первого шага; в live дополнительные поля открыты, поскольку паузу нужно задать явно |
| Длинная формула и методические пояснения рядом с результатом | Виден итоговый бюджет/резерв; методика отдельно | Результат легче сопоставить с лимитом |
| Рейтинг всех кандидатов What-if всегда на экране | «Подобрать ветку для ускорения» | Дополнительный путь не мешает ручному сценарию |
| Полный Trace ID, время старта и ревизия в основной сводке | Короткий ID с копированием полного; убраны время и ревизия из сводки | Технические refs остаются в данных/экспорте |

## Что намеренно осталось видимым

Маркер демоданных, предупреждения о неполноте, ошибки загрузки, ограниченное покрытие аудита, признак черновика и отсутствие реального применения. Их сокрытие могло бы привести к неправильному выводу о состоянии приложения.

## Проверка

Production build и 26 автотестов прошли. Через браузер проверены выбор связи → редактор → рекомендация (1650 мс при бюджете 2000 мс), открытие дополнительных полей, раскрытие расчёта аудита и плана, переход через «Ещё», раскрытие таблицы связей на 390 px. Ширина документа на мобильном экране остаётся 390 px. Ошибки console проверены отдельно в финальном просмотре.

Скриншоты актуального варианта: screenshots/graph-simple-desktop.jpg и graph-simple-mobile.jpg. Старые снимки оставлены как история предыдущего варианта.

Следующий шаг — дать участнику команды без подсказок найти проблемную связь и подготовить исправление. По его действиям оценить, что трудно найти в свёрнутых блоках. Уменьшение числа видимых элементов само по себе не доказывает рост удобства.


## Уточнение: вкладки вместо раскрывающихся блоков

- Граф: «Карта», «Связи», «О данных». Таблица связей — самостоятельное представление. Выбор связи в таблице открывает карту с инспектором.
- Время сервисов: «Время ответа» и «О данных», без лишнего раскрываемого контейнера вокруг таблицы.
- Аудит: «Находки» и «Проверки». Находка: «Решение», «Обоснование», «Примеры трасс». Обоснование объединяет объяснение, расчёт, источник и риски в один связный блок.
- Настройки: «Редактор», «Текущие настройки», «Как считается бюджет». Все четыре поля доступны в форме, дополнительные параметры выделены обычным блоком. Переключение вкладок не уничтожает черновик.
- Моделирование: «Сценарий», «Кандидаты», «О модели». Добавление кандидата возвращает к сценарию. Выбранные ветки сохраняются между вкладками.
- В инспекторе ссылки на план и примеры трасс доступны непосредственно.

Использован один общий Tabs без новой библиотеки. Проверены переключение стрелками, Home/End предусмотрены общим компонентом, сохранение значения 900 мс при редактор → текущие настройки → редактор, бюджет рекомендации 1650 мс, переход из таблицы на карту, обоснование/примеры/покрытие аудита, сохранение сценария и мобильная ширина 390 px. Сборка и 26 автотестов проходят; они проверяют расчёты и контракты, визуальные сценарии проверены через браузер.

Актуальный снимок: screenshots/policies-tabs-desktop.jpg. Старые снимки сохраняют предыдущие состояния интерфейса.

## Явная цель редактирования

Над вкладками настроек добавлен постоянный выбор исходящего вызова: caller → callee и операция. Подпись указывает владельца настроек и область их действия. Для демопримера это orders → payment, POST /charge; не глобальные настройки payment. Выбор доступен на всех вкладках. Build прошёл, видимость контекста при переходе между вкладками проверена в браузере.

## Обычные текстовые обозначения

Символьные стрелки в названиях вызовов заменены словами «Из caller в callee». Точки-разделители заменены запятыми, стрелки у ссылок на трассы удалены. Обновлены демоданные и заголовок вкладки браузера. Направленные линии графа сохранены как часть диаграммы. Build и 26 тестов проходят; на странице настроек проверено отсутствие этих символов в тексте.
