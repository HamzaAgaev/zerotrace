# app

**Зачем:** серверные модули одного Python-процесса. A (Никита) собирает
здесь общий HTTP-сервер и подключает роутеры всех трёх бэкендеров; каждый
владеет своим подпакетом.

**Подпакеты:**

| Пакет | Владелец | Назначение |
|---|---|---|
| `data_api/` | B (Миша) | Product API данных для фронтенда (P7): список и детали трасс. |
| `otlp_api/` | B (Миша) | Приём телеметрии `POST /v1/traces` (P1): токен → decode → normalize → запись. |

Модули A (server/startup, integrations, control) и C (analytics_api,
reports) подключаются сюда же по мере готовности.
