# Серверные модули

Один пакет `app` содержит общий HTTP-сервер и прикладные модули.

| Пакет | Назначение |
|---|---|
| `server/` | Сборка HTTP-приложения, lifecycle, UI и фоновый тикер assembly |
| `control/` | Планы, применение, журнал, лаборатория и прогоны |
| `integrations/` | Реестр источников и адаптер конфигурации |
| `data_api/` | Список и детали трасс |
| `otlp_api/` | Приём OTLP и запись через repository |
| `analytics_api/` | Аудит, рекомендации и сравнение |
| `reports/` | Формирование аналитических отчётов |

[Границы и зависимости](../../docs/architecture/components.md).
